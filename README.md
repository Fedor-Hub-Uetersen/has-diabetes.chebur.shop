# e# 🩸 e-Diabetes — Онлайн-щоденник самоконтролю діабету

Адаптивний лендинг-візитка та інформаційний портал для сервісу щоденного самоконтролю рівня цукру, обліку інсуліну та хлібних одиниць **e-Diabetes**.

## 🚀 Основні можливості

- **Мультимовність (UA / DE / EN):** Миттєве перемикання інтерфейсу між українською, німецькою та англійською мовами без перезавантаження сторінки.
- **Світла та темна теми:** Перемикання оформлення (`Light / Dark Mode`) із запам'ятовуванням вибору користувача в `localStorage`.
- **Інтерактивні картки-спойлери:** Клікабельні блоки можливостей із плавним розкриттям детального опису та автоматичним приховуванням відсутніх зображень без «битих» рамок.
- **Інтеграція з екосистемою:**
  - Прямий перехід до робочого щоденника: [e-diabetes.chebur.shop](https://e-diabetes.chebur.shop)
  - Верхній екстрений промо-банер сервісу медичних карток: [sos-id.online](https://sos-id.online)
  - Платформа розробки: [tech.chebur.shop](https://tech.chebur.shop)
- **Юридичний захист:** Вбудований медичний дисклеймер (Medical Disclaimer) трьома мовами.
